Assemblage is a highly scalable and configurable infrasture for binary analysis. This project is led by Prof. [Kristopher Micinski](https://ecs.syracuse.edu/faculty-staff/kristopher-micinski) with industrial collaboration. 
We are currently collecting binaries and do machine learning work on it.

We intended to release this project around April.
