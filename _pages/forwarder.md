# WeChat-Telegram Message Auto-Forwarder

![](https://img.shields.io/badge/-Python-black?style=flat-square&logo=Python&labelColor=f0f0f0&logoColor=3776AB)![](https://img.shields.io/badge/-WebDriver-black?style=flat-square&logo=firefox&labelColor=f0f0f0&logoColor=orange)

## Description

Two years ago US government was talking about banning WeChat and TikTok, recently AT&T turns out blocking some China ISP, which brings trouble if you want to use WeChat but don't staying connected to VPN or proxy, that's why we created this program to transfer all text and image message from WeChat account to Telegram bot. Once you run this program on your server or desktop and login by scanning QR-code, every message you received from WeChat will be automatically forwarded to telegram and you will received a notification push for it.
